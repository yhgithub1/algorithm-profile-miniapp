# algorithm-profile-miniapp

微信小程序创新大赛项目：**算法侧写 / 数字投影**。

> 互联网只能看见你的行为痕迹，无法读懂你的想法。算法眼中的你，只是碎片拼成的投影。

## 当前锁定的产品主线

这不是人格测试，也不把用户归类成某种固定类型。

```text
选择一个平台观察视角
        ↓
回答该平台真实场景问题
        ↓
每个答案变成一块彩色行为碎片
        ↓
数字分身逐渐出现
        ↓
多条行为痕迹汇聚后才允许生成概率推断
        ↓
用户可以当场反馈：比较像我 / 不确定 / 完全不是
        ↓
继续解锁其他平台视角
        ↓
看到不同平台留下的局部投影、一致、矛盾与空白
```

## MVP 先做三个观察窗口

### 🥡 美团 · 生活消费视角

主要观察：
- 即时消费
- 餐饮选择
- 熟悉 / 尝新
- 下单前比较
- 计划与临时决策
- 消费后的公开表达

### 🎵 抖音 · 内容注意力视角

主要观察：
- 内容停留深度
- 兴趣集中 / 跨主题探索
- 主动搜索
- 热点追踪
- 评论 / 转发 / 安静观看
- 有用内容是保存、查证还是看完即走

### 📕 小红书 · 生活决策视角

主要观察：
- 做决定前是否搜攻略
- 同一问题会看多少信息
- 收藏后是否会再次使用
- 被种草后立即行动还是继续查证
- 熟悉偏好 / 新生活方式探索
- 评论、分享与发布行为

未来平台可以继续扩展，但不改变底层模型。

## 底层模型

当前只保留 5 条连续行为光谱轴，全部用于内部计算：

1. 决策方式
2. 探索方式
3. 信息深度
4. 表达方式
5. 计划方式

规则：
- 单个答案不能直接生成强画像结论；
- 一个行为轴至少需要 2 条相关痕迹才视为“被观察”；
- 多条证据方向不一致时，显示“不同场景表现不一致”或“暂无明显行为倾向”；
- 证据不足时直接显示“尚未充分观察”；
- 不输出 MBTI 字母、人格类型、动物类型、XX派 / XX者等身份分类。

## 推断文案固定格式

```text
【观测痕迹】 → 算法推断：你可能……
```

所有推断必须使用“可能 / 存在 / 目前观察到”等概率表达。

用户可以对每条推断反馈：
- 比较像我
- 不确定
- 完全不是

当用户否定推断时，页面明确提示：

> 算法看到了行为，却可能误解了原因。

## 核心视觉

- 暖白 / 石墨灰为主，不做星空、电竞霓虹和雷达图；
- 中心为灰白数字分身；
- 每次选择后，一个彩色行为碎片飞向分身并附着；
- 已观察的部分逐渐出现颜色，未观察部分继续保持灰白；
- 单平台结果页中，数字分身向外放射推断线条；
- 跨平台页面保留大量空白，明确表达“算法永远看不到完整的人”。

## 当前页面

```text
pages/index             核心世界观首页
pages/platforms         选择平台观察视角
pages/survey            场景问答 + 行为碎片飞入数字分身
pages/platform-result   放射式概率推断 + 用户纠错
pages/merge             多平台局部投影 / 一致 / 矛盾 / 空白
```

仓库中较早的截图分析、算法图谱、动物角色等实验代码暂时保留，但不进入当前 MVP 主线。

## 产品边界

- 不读取任何平台真实后台用户标签；
- 不宣称知道平台真实内部画像算法；
- 不把行为推断包装成事实；
- 不进行心理诊断；
- 不根据单个行为推断高敏感属性；
- 不强行填满用户画像；
- 不把跨平台结果包装成“完整真实的你”。

## 一句话介绍

> **看看互联网如何从你留下的一点点行为痕迹，拼出一个可能正确、也可能误解你的数字投影。**
