# algorithm-profile-miniapp

微信小程序创新大赛项目：**算法侧写 / 数字人格**。

> 同一个你，在美团、抖音、小红书和淘宝眼里，可能是四个不同的人。

## 当前主体验

```text
美团 / 抖音 / 小红书 / 淘宝
              ↓
     ┌────────┴────────┐
     ↓                 ↓
回答生活化问题      上传推荐页截图
     ↓                 ↓
本地问答规则       OCR + 图片分类
     └────────┬────────┘
              ↓
       单个平台算法画像
              ↓
       跨平台数字分身
```

第一版不会读取任何第三方 App 账号。用户只根据自己的真实生活习惯或主动上传的推荐页截图进行分析。

## 两种画像方式

### 1. 回答几个问题

完全在微信小程序本地完成，不需要后端。

### 2. 上传推荐页截图

不调用 Qwen、GPT、Gemini 等商业多模态 API。

当前技术链路：

```text
截图
↓
PaddleOCR：文字 / 价格 / 优惠
↓
固定页面切片：推荐卡区域
↓
OpenCLIP：图片内容零样本分类
↓
标准 JSON
↓
小程序本地透明规则
↓
“这个 App 正在给我看什么”
```

截图分析后端位于 `backend/`，详细启动方式见 `backend/README.md`。

## 四个平台

### 🥡 美团

问答会观察：外卖依赖、客单预算、优惠敏感、餐厅探索、时效偏好。

截图模式重点识别：

- 推荐餐饮类别
- 可识别价格带
- 满减 / 神券 / 券后价等促销词
- 首页推荐内容的集中程度

### 🎵 抖音

问答会观察：观看深度、内容主动性、兴趣跨度、热点敏感、互动表达。

截图模式重点识别：

- 每张推荐视频的大致内容类别
- 多张截图后的主题分布

由于一张抖音截图通常只有一个视频，截图模式建议连续上传 5～9 张。

### 📕 小红书

问答会观察：主动搜索、决策规划、生活探索、表达分享、种草响应。

截图模式重点识别：

- 首页推荐卡的旅行 / 美食 / 穿搭 / 数码 / 家居等类别
- 攻略 / 教程 / 测评 / 清单等决策型关键词
- 多张首页截图中的稳定主题

### 🛒 淘宝

问答会观察：价格敏感、购买研究、即时购买、品牌倾向、新品兴趣。

截图模式重点识别：

- 推荐商品类别
- 可识别价格带
- 券后价 / 补贴 / 大促 / 优惠等促销词
- 推荐品类集中度

## 跨平台数字分身

四个平台会把少量局部信号映射到统一的跨平台维度：

1. 价格敏感
2. 探索倾向
3. 计划性
4. 深挖倾向
5. 社交表达
6. 经典偏好
7. 便利优先

完成两个以上 App 后，`pages/merge` 会开始展示：

- 四个平台分别认识了用户的哪一面
- 哪些倾向在不同 App 中重复出现
- 合并后形成的“数字分身”
- 为什么生活碎片组合后会显得越来越完整

截图模式会保持保守：如果截图本身不能支持某项行为结论，对应跨平台维度保持中性，不因为“看到了某个内容”就直接断言用户具备某个人格。

## 当前页面

```text
pages/index             首页
pages/platforms         美团 / 抖音 / 小红书 / 淘宝入口
pages/screenshot        推荐页截图上传与识别结果
pages/survey            生活化问答
pages/platform-result   问答生成的单平台画像
pages/merge             跨平台数字分身

pages/select            高级算法实验室：线索选择
pages/profile           动态推断图谱 + 数字人格 + 用户纠错
pages/impact            推荐 / 广告 / 优惠仿真
pages/match             双人圈子融合实验
pages/share             数字人格分享卡
```

## 截图分析后端

```text
backend/
├─ app/main.py
└─ app/services/
   ├─ ocr_engine.py     PaddleOCR
   ├─ clip_engine.py    OpenCLIP
   ├─ layout.py         透明页面切片规则
   └─ analyzer.py       标准化识别结果
```

开发时默认接口：

```text
http://127.0.0.1:8000
```

小程序配置位置：

```text
miniprogram/config/api.js
```

真机 / 正式发布时，需要把它换成你自己的 HTTPS 服务地址，并在微信公众平台配置合法 request/uploadFile 域名。

## 产品边界

- 不登录或读取美团、抖音、小红书、淘宝真实账号
- 不保存 Cookie、Token、登录态或设备指纹
- 不声称知道这些平台的真实内部算法
- 不暗示这些平台之间实际共享用户数据
- 所有结果统一使用“可能 / 模拟 / 倾向”表达
- 跨平台合并只使用用户主动填写或主动上传的数据
- 不推断健康、宗教、政治立场等高敏感属性
- 当前截图后端不把原始图片写入磁盘

## 本地运行

### 只体验问答

1. `git pull`
2. 使用微信开发者工具导入仓库根目录
3. 编译

### 开启截图识别

先启动后端：

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

然后在微信开发者工具中进行本地调试。

更详细的技术说明见 `docs/DEVELOPMENT.md` 和 `backend/README.md`。
