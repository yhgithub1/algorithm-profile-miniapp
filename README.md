# algorithm-profile-miniapp

微信小程序创新大赛项目：**算法侧写 / 数字人格**。

> 别人通过问卷认识你，算法通过行为认识你。

## 当前版本：完整本地 MVP

主体验已经跑通：

```text
真实兴趣 / 行为线索
        ↓
可解释人物推断图谱
        ↓
8 维数字人格
        ↓
用户反驳 / 纠错
        ↓
推荐 / 广告 / 优惠仿真
        ↓
双人圈子融合实验
        ↓
“算法眼中的我”分享卡
```

## 已实现功能

- 27 个第一版兴趣 / 行为线索
- 分组选择与 4 组比赛快速演示预设
- 多层规则图谱推断
- noisy-or 多证据置信度合并
- 动态 Canvas 推断关系图
- 8 个数字人格维度
- 阶段性人格命名
- `符合 / 不确定 / 不符合` 用户纠错
- 纠错后图谱、分数、人格同步重算
- 推荐内容、广告促销、差异化优惠本地仿真
- 双人圈子重合度 / 行为相似度 / 兴趣互补度
- 自动生成共同话题
- Canvas 分享卡、保存相册、微信分享

## 8 个数字人格维度

1. 探索度
2. 深挖度
3. 怀旧度
4. 价格敏感
5. 决策谨慎
6. 内容主动性
7. 社交表达
8. 热点敏感

这些不是心理学量表。它们只表示用户主动提供的行为证据在本项目模拟规则中的位置。

## 页面

- `pages/index`：项目首页
- `pages/select`：真实线索选择
- `pages/profile`：人物图谱 + 数字人格 + 用户纠错
- `pages/impact`：推荐 / 广告 / 优惠仿真
- `pages/match`：双人圈子融合实验
- `pages/share`：数字人格分享卡

## 本地运行

1. 克隆仓库。
2. 使用微信开发者工具导入仓库根目录。
3. 在 `project.config.json` 中使用自己的小程序 AppID，或使用开发者工具可用的测试方式。
4. 编译。
5. 第一轮建议直接使用“比赛快速演示”里的预设走完整流程。

## 推荐演示路径

### 怀旧深潜

`周杰伦 + QQ空间 + 看完视频 + 主动搜索`

适合展示：

`事实线索 → 华语流行 / 早期互联网 → 怀旧文化 → 数字人格 → 推荐影响`

### 理性比价

`找优惠券 + 看评价 + 等活动 + 主动搜索`

适合展示：

`消费行为 → 价格敏感 / 决策谨慎 → 优惠分配仿真`

### 安静稳定

`熟悉内容 + 私人消费 + 不追热点 + 看完视频`

适合展示：数字维度不是只会向“高分”方向变化，也可以形成低社交、低热点、熟悉优先等另一端画像。

## 产品边界

当前版本：

- 不抓取美团、携程、电商等第三方商业平台真实价格
- 不模拟第三方登录
- 不保存第三方账号 Cookie / Token
- 不读取通讯录、聊天记录或其他应用行为
- 不推断健康、宗教、政治立场等高敏感属性
- 所有结果均强调“模拟 / 倾向 / 可能”，不是事实判断

差异化优惠模块只是透明公式仿真，不代表任何真实平台规则。
