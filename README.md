# algorithm-profile-miniapp

微信小程序创新大赛项目：**算法侧写 / 数字人格**。

## 当前目标

先完成最小闭环：

1. 用户选择 2～5 个兴趣/行为线索
2. 本地规则引擎进行可解释推断
3. 展示“行为 → 兴趣 → 潜在特征 → 人格维度”的人物图谱
4. 每个推断都保留来源、权重和解释

## V0.1 开发原则

- 微信小程序原生开发
- 第一阶段不接大模型
- 第一阶段不接第三方商业平台价格接口
- 推断以本地规则库为核心，结果可复现、可解释
- 后续再加入反馈、分享卡、算法影响仿真和社交匹配

## 第一阶段页面

- `pages/index`：首页
- `pages/select`：兴趣/行为线索选择
- `pages/profile`：人物图谱 / 算法侧写结果

## 核心目录

```text
miniprogram/
├─ pages/
│  ├─ index/
│  ├─ select/
│  └─ profile/
├─ data/
│  ├─ tags.js
│  └─ rules.js
└─ utils/
   └─ inference.js
```

> 当前最重要的不是“16 种人格”，而是先把可解释的人物推断图谱跑通。
