# Algorithm Profile · Web V2

这是用于快速验证产品体验的网页原型，不替代现有微信小程序代码。

当前主线：

```text
首页
→ 7 个日常场景选择
→ 第 3 题后提前出现一次“算法已经开始猜”的中间反馈
→ 数字分身持续留下彩色行为痕迹
→ 最终输出跨场景行为发现
→ 算法最可能误判的地方
→ 推荐反馈回路
→ 三个平台分别看见的局部
```

结果页不输出 MBTI 式人格类型，也不展示假精确分数。重点寻找：

- 跨场景行为差异
- 表面矛盾背后的共同模式
- 低可见行为与显性互动的差别
- 平台可能出现的误判
- 行为与推荐之间的反馈回路

## 本地运行

```bash
cd web
npm install
npm run dev
```

Vite 会打印本地访问地址，通常是：

```text
http://localhost:5173
```

手机预览时可运行：

```bash
npm run dev -- --host 0.0.0.0
```

然后在同一局域网内通过电脑的局域网 IP 访问。

## 当前边界

- 纯前端，不读取第三方平台账号
- 不调用大模型或后端 API
- 不代表美团 / 抖音 / 小红书真实内部标签
- 所有推断均为基于主动选择的行为模拟

这版主要验证：**页面是否像一个互动产品、数字分身是否有存在感、最终行为发现是否真的能提供用户自己没有直接输入的新信息。**
